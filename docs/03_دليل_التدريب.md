> **لمن هذا الدليل؟**
> - **لك أنت** كمطوّر وموزّع: لتتعلم البرنامج كمستخدم، ثم تدرّب زبائنك (الجزء 6 خطة تدريب جاهزة).
> - **لصاحب المحل والمدير والكاشير:** كل جزء مكتوب خطوة بخطوة.
>
> **كيف تتدرب بنفسك الآن؟** شغّل البرنامج ببيانات تجريبية (سوبرماركت كامل بمبيعات شهر):
> ```
> python tools/demo_data.py demo_data
> set SHOP_DATA_DIR=demo_data && python main.py        (ويندوز)
> SHOP_DATA_DIR=demo_data python main.py               (لينكس/ماك)
> ```
> الدخول: `admin` / `admin` (مدير) أو `cashier` / `1234` (كاشير).

## 1. المفاهيم الأساسية في 5 دقائق

| المفهوم | المعنى |
|---|---|
| **الأدوار** | **مدير النظام** (كل شيء)، **مدير المحل** (كل شيء عدا الإعدادات والمستخدمين)، **كاشير** (بيع، فواتير، عملاء، صندوق) |
| **إذن المدير** | إذا احتاج الكاشير عملية ممنوعة (خصم كبير، تغيير سعر، تجاوز حد دين) تظهر نافذة يكتب فيها المدير اسمه وكلمة مروره فوراً، وتُسجَّل في سجل العمليات |
| **الوردية** | فترة عمل كاشير على جهاز: تبدأ برصيد افتتاحي في الدرج وتنتهي بعدّ النقود. تكشف العجز والزيادة |
| **الوحدة** | لكل صنف وحدة أساسية (حبة) ويمكن إضافة وحدات أكبر (كرتونة = 24 حبة) بباركود وسعر خاص |
| **الدفعة** | كمية من صنف بتاريخ صلاحية واحد. البرنامج يبيع الأقرب انتهاءً أولاً |
| **الآجل** | بيع بالدين لعميل مسجّل (الدفتر) |
| **الجهاز الرئيسي والفرعي** | في المحلات ذات أكثر من كاشير: جهاز رئيسي يحفظ البيانات، والبقية تتصل به عبر شبكة المحل |

**قاعدة مهمة للزبون:** كل شيء يُحفظ فوراً. لا يوجد زر «حفظ» عام. ونسخة احتياطية تُؤخذ تلقائياً يومياً وعند الإغلاق.

## 2. التركيب وأول تشغيل

### 2.1 التركيب على جهاز المحل (ويندوز)
1. انسخ مجلد البرنامج `ShopAccounting` (المبني بـ `build_exe.bat`) إلى `C:\ShopAccounting`.
2. أنشئ اختصاراً لـ `ShopAccounting.exe` على سطح المكتب.
3. شغّله. أول مرة قد يسأل جدار الحماية (عند الشبكة): اختر **سماح**.

### 2.2 أول دخول
1. المستخدم `admin` وكلمة المرور `admin`.
2. يطلب البرنامج **تغيير كلمة المرور فوراً**. اختر كلمة قوية واحفظها عند المالك.
3. يظهر **معالج الإعداد الأول**: اسم المحل، الهاتف، العنوان، العملة، الدولة (لواتساب)، الضريبة، نقاط الولاء، رقم واتساب المالك. اضغط **ابدأ ✓**.

### 2.3 تجهيز البيانات (أهم ساعة في حياة الزبون مع البرنامج)
بالترتيب:
1. **المستخدمون:** الإعدادات ← المستخدمون ← «+ مستخدم» لكل كاشير (دور: كاشير).
2. **الطابعة:** الإعدادات ← الطباعة ودرج النقود ← اختر الطابعة وعرض الورق (80 أو 58 مم) ← «معاينة فاتورة تجريبية».
3. **المنتجات** — ثلاث طرق:
   - **الأسرع:** املأ ملف Excel بالأعمدة (الاسم، الباركود، الفئة، الوحدة، سعر التكلفة، سعر البيع، الكمية، الحد الأدنى، رمز الميزان) واحفظه CSV، ثم المخزون ← **📥 استيراد من Excel**. (صدّر أولاً ملفاً فارغاً بـ **📤 تصدير إلى Excel** لترى الشكل).
   - **بالمسح:** في نقطة البيع امسح أي باركود غير مسجل ← يسألك البرنامج «إضافته كمنتج جديد؟».
   - **يدوياً:** المخزون ← **+ منتج جديد**.
4. **الأصناف بلا باركود** (خبز، خضار): في بطاقة المنتج اضغط **توليد** لباركود داخلي، وفعّل «مفضّل» ليظهر زراً سريعاً في نقطة البيع.
5. **الموزونات:** للملحمة والخضار ضع **رمز الميزان (PLU)** في بطاقة المنتج بنفس الرقم المبرمج في الميزان.
6. **الكراتين:** في بطاقة المنتج ← «+ إضافة وحدة»: كرتونة، عدد الحبات 24، باركود الكرتونة، سعرها.
7. **الديون القديمة:** العملاء ← + عميل جديد ← «رصيد سابق». ومثلها للموردين.
8. **رأس المال والبنك (اختياري):** المحاسبة ← «عملية مالية» ← «رصيد بنك افتتاحي» أو «إيداع رأس مال».

## 3. يوم عمل الكاشير

### 3.1 بداية الوردية
1. سجّل الدخول باسمك (ليس باسم المدير).
2. أول عملية بيع تطلب **فتح وردية**: عُدّ النقود في الدرج (الفكّة) واكتب المبلغ ← **🔓 فتح وردية**.

### 3.2 البيع — الطريقة السريعة
| ما تريد | ماذا تفعل |
|---|---|
| إضافة صنف | امسح الباركود (أو اكتب جزءاً من الاسم ثم Enter) |
| 3 قطع مرة واحدة | اكتب `3*` ثم امسح الباركود |
| صنف موزون | امسح ملصق الميزان — الوزن يُقرأ تلقائياً |
| زيادة/نقص الكمية | **+** أو **−** |
| حذف سطر | **Delete** |
| تغيير الكمية بالكتابة | **F8** |
| كرتونة بدل حبة | امسح باركود الكرتونة، أو **F5** على السطر |
| سعر مختلف | **F10** (يحتاج إذن مدير للكاشير) |
| خصم على الفاتورة | **F9** (مبلغ أو نسبة؛ فوق الحد يحتاج إذن مدير) |
| الزبون يسأل «بكم هذا؟» | زر **🔍 فحص سعر** — لا يُضاف للفاتورة |
| نقدي بالضبط بدون نافذة | **F12** |
| الدفع | **F2** أو **Enter** وخانة البحث فارغة |

**العروض تُطبّق وحدها:** إذا كان على الصنف عرض (مثل «اشترِ 2 واحصل على 1») يظهر سطر وردي 🎁 تحت الإجمالي بقيمة الخصم. لا تفعل شيئاً.

### 3.3 نافذة الدفع
1. اكتب المبلغ الذي أعطاك إياه الزبون، أو اضغط زر الورقة (10، 20، 50...). يظهر **الباقي للزبون** بخط كبير.
2. **بطاقة:** اكتب المبلغ في خانة البطاقة، أو «بطاقة بالكامل».
3. **مختلط:** جزء نقدي وجزء بطاقة معاً.
4. **آجل (دين):** اختر العميل أولاً (**F4**)، ثم «الباقي دين على العميل» أو «آجل بالكامل».
5. **Enter** لإتمام البيع. تُطبع الفاتورة إن كان خيار الطباعة مفعّلاً، ويُفتح درج النقود.

### 3.4 الزبون الدائم ونقاط الولاء
1. **F4** ← ابحث عن العميل بالاسم أو الهاتف (أو «+ عميل جديد»).
2. يظهر على الزر رصيد دينه ونقاطه 🎁.
3. لاستبدال النقاط: زر **🎁 استبدال نقاط** ← اكتب عدد النقاط ← يُخصم من الفاتورة.
4. بعد البيع يظهر «🎁 +25 نقطة» وتُطبع النقاط على الفاتورة.

### 3.5 مواقف يومية
| الموقف | الحل |
|---|---|
| الزبون نسي غرضاً وسيعود | **F6 تعليق** الفاتورة، اخدم الزبون التالي، ثم **F7** لاسترجاعها |
| طباعة الفاتورة الأخيرة مرة أخرى | **F11** |
| فتح الدرج لإعطاء فكّة | زر **💰 فتح الدرج** (يُسجّل في سجل العمليات) |
| صنف منتهي الصلاحية ظهر تحذير أحمر ⛔ | لا تبعه؛ أبلغ المدير ليتلفه من شاشة الصلاحية |
| الزبون يريد إرجاع صنف | الفواتير والمرتجعات ← ابحث برقم الفاتورة ← **↩ مرتجع** ← اختر الكمية ← نقداً أو خصم من الدين |
| زبون يسدد ديناً | العملاء ← اختره ← **💰 تسديد دفعة** |
| زبون يعطي شيكاً عن دينه | العملاء ← اختره ← **📥 استلام شيك** (يحتاج صلاحية المدير) |

### 3.6 نهاية الوردية
1. الصندوق والورديات ← **🔒 إغلاق الوردية وعدّ النقود**.
2. عُدّ النقود بالفئات (200، 100، 50...) — البرنامج يجمعها.
3. يظهر **المتوقع** و**المعدود** و**الفرق** (عجز أو زيادة).
4. **🖨 طباعة تقرير الوردية** وسلّمه مع النقود للمدير.

> **قاعدة ذهبية للكاشير:** لا تأخذ ولا تضع مالاً في الدرج بدون تسجيله: استخدم **⬆ سحب نقدي** أو **⬇ إدخال نقدي** مع السبب. وإلا سيظهر عجز أو زيادة باسمك.

## 4. مهام المدير وصاحب المحل

### 4.1 كل صباح (5 دقائق)
1. **لوحة التحكم:** مبيعات أمس، النواقص، الصلاحية، **الشيكات المستحقة خلال أسبوع**.
2. **الشيكات:** هل هناك شيك صادر يستحق غداً؟ تأكد من رصيد البنك.
3. **الصلاحية:** أتلف المنتهي، واعمل عرضاً على القريب من الانتهاء.

### 4.2 استلام بضاعة من المورد
1. الموردون والمشتريات ← **🧾 فاتورة مشتريات جديدة** ← اختر المورد.
2. امسح باركود كل صنف (أو باركود الكرتونة للشراء بالكرتونة).
3. عدّل الكمية وتكلفة الوحدة وسعر البيع، واكتب **الصلاحية** (مثل 2027-03-31) للأصناف الغذائية.
4. «دفع كامل المبلغ» أو اكتب المدفوع الآن؛ الباقي يصبح ديناً للمورد.
5. **حفظ الفاتورة**: يزيد المخزون وتُحدَّث التكلفة بالمتوسط المرجّح.

### 4.3 إرجاع بضاعة للمورد
الموردون ← اختر المورد ← **↩ مرتجع للمورد** ← امسح الأصناف ← الكمية والسعر المتفق عليه ← السبب ← حفظ. يُخصم من المخزون ومن حساب المورد.

### 4.4 الطلبيات الذكية (بدل الوقوف أمام الرفوف بورقة وقلم)
1. 🧠 الطلبيات الذكية ← «احسب سرعة البيع من آخر 30 يوماً، واطلب ما يكفي 14 يوماً» ← **🔄 احسب**.
2. اختر المورد من القائمة.
3. **📱 إرسال الطلبية للمورد (واتساب)** — الرسالة جاهزة بالأصناف والكميات بالكرتونة.
4. عند وصول البضاعة: **🧾 تحويلها لفاتورة مشتريات** — الأصناف والكميات معبأة، عدّل الأسعار واحفظ.

### 4.5 المخزون والجرد
- **📋 جرد:** اكتب الكمية الفعلية على الرف؛ الفرق يُسجَّل تلقائياً (نقص = خسارة).
- **± تعديل الكمية:** لتالف أو هدية أو استهلاك (اكتب السبب: «تالف» أو «منتهي» يُحتسب خسارة).
- **📜 حركة الصنف:** كل ما دخل وخرج من الصنف ومن قام به.
- **🏷 طباعة ملصقات:** ملصقات أسعار بالباركود.
- **النواقص فقط:** قائمة ما وصل للحد الأدنى.

### 4.6 الديون
- **العملاء والديون:** كشف حساب لكل عميل، **🖨 طباعة الكشف**، **💬 تذكير واتساب**، و**📣 تذكير جماعي للمدينين** (رسالة لكل مدين بضغطة).
- **حد الدين:** في بطاقة العميل. البرنامج يمنع تجاوزه إلا بإذن المدير.
- **⚖ تسوية:** مسامحة بمبلغ بسيط أو تصحيح (تظهر في التقارير كتسوية).

### 4.7 الشيكات
- **استلام شيك من عميل:** 🏦 الشيكات ← 📥 ← العميل، المبلغ، الرقم، البنك، تاريخ الاستحقاق.
- **إعطاء شيك لمورد:** 📤 ← المورد... (أو من شاشة الموردين ← «📤 شيك مؤجل»).
- **يوم الاستحقاق:** اختر الشيك ← **✓ صُرف في البنك**، أو **↩ راجع** (يعود الدين تلقائياً).
- الألوان: 🟥 فات موعده ولم يُحدَّث، 🟧 خلال أسبوع.

### 4.8 العروض ونقاط الولاء
- 🎁 العروض والولاء ← **+ عرض جديد**:
  - **اشترِ واحصل مجاناً:** الصنف، اشترِ 2، واحصل على 1.
  - **كمية بسعر ثابت:** 3 قطع بـ 10.
  - **خصم نسبة:** على صنف أو **فئة كاملة** (مثل المنظفات 15%).
  - تاريخ البداية والنهاية؛ العرض يتوقف وحده.
- **نقاط الولاء:** الإعدادات ← نقاط الولاء ولوحة المالك. المثال الموصى به: نقطة لكل 1 شيكل، النقطة = 0.05، أقل استبدال 100 ← الزبون يسترد 5%.

### 4.9 المصاريف
💸 المصاريف ← النوع (كهرباء، إيجار...) ← المبلغ ← «من الصندوق» إذا دُفع من الدرج، وأزِل العلامة إذا دفعه المالك من جيبه أو من البنك.

### 4.10 التقارير (ماذا تقرأ ومتى)
| التقرير | متى | ماذا تبحث |
|---|---|---|
| الأرباح والخسائر | أسبوعياً وشهرياً | صافي الربح، هامش الربح (الجيد للبقالة 15-25%) |
| الأصناف الأكثر مبيعاً (حسب الربح) | شهرياً | ما الذي يربحك فعلاً؛ لا ينفد أبداً |
| أصناف راكدة | شهرياً | مال مجمّد: اعمل عليها عرضاً أو أرجعها للمورد |
| ساعات الذروة | عند تنظيم الدوام | متى تحتاج كاشيراً إضافياً |
| حسب الكاشير | أسبوعياً | الخصومات الكثيرة من كاشير معيّن |
| سجل العمليات | عند الشك | من غيّر سعراً، من فتح الدرج، من حذف صنفاً |

### 4.11 المحاسبة والميزانية (لصاحب المحل والمحاسب)
- **الميزانية العمومية:** كم يملك المحل وكم عليه وصافي حق المالك.
- **قائمة الدخل:** الربح الحقيقي للفترة.
- **ميزان المراجعة:** أعطه للمحاسب القانوني (📤 تصدير أو 🖨 طباعة). انقر مرتين على أي حساب لكشفه.
- **➕ عملية مالية:** رأس مال، إيداع في البنك، سحب من البنك، شراء معدات، قرض وسداد قسط.
- **القيود اليدوية** للمحاسب فقط، ويمكن إلغاء قيد (يبقى ظاهراً كملغى).
> اقرأ «02_المحاسبة_ببساطة.md» لفهم المصطلحات.

### 4.12 لوحة المالك على الجوال وملخص اليوم
- الإعدادات ← نقاط الولاء ولوحة المالك ← فعّل «تشغيل لوحة المالك» ← أعد تشغيل البرنامج.
- من جوال المالك على شبكة المحل افتح العنوان الظاهر (مثل `http://192.168.1.10:8765/owner`) وسجّل الدخول بحساب مدير. احفظه على الشاشة الرئيسية للجوال.
- من خارج المحل: ثبّت **Tailscale** (مجاني) على جهاز المحل والجوال بنفس الحساب، واستخدم عنوان Tailscale.
- **📱 ملخص اليوم للمالك** في لوحة التحكم: رسالة واتساب بمبيعات اليوم وربحه ونقده وتنبيهاته.

### 4.13 عدة أجهزة كاشير
1. في الجهاز الرئيسي: الإعدادات ← هذا الجهاز والشبكة ← إعداد الشبكة ← «جهاز رئيسي». سجّل العنوان ورمز الربط.
2. في كل كاشير: «نقطة بيع فرعية» ← العنوان ورمز الربط ← 🔌 اختبار الاتصال.
3. أعد تشغيل البرنامج في كل الأجهزة. لكل جهاز ورديته وصندوقه وطابعته.
4. عدد الأجهزة المسموح حسب الترخيص.

### 4.14 النسخ الاحتياطي (لا تتجاهله أبداً)
- نسخة تلقائية يومياً وعند الإغلاق.
- الإعدادات ← النسخ الاحتياطي ← **نسخة ثانية تلقائية في مجلد سحابي**: اختر مجلداً داخل Google Drive أو OneDrive.
- الاستعادة: «♻ استعادة المحددة» (من الجهاز الرئيسي فقط).

### 4.15 المستشار الذكي 🤖 (جديد في 5.0)
- افتحه كل صباح: التوصيات مرتبة من الأخطر (⛔ أحمر) إلى الإيجابي (✅ أخضر).
- كل توصية فيها رابط ينقلك للإجراء: «الطلبيات الذكية» لصنف سينفد، «إنشاء عرض» لبضاعة راكدة، «العملاء» لزبون توقف عن الشراء...
- **تحليل ABC:** أصناف A (تصنع 80% من مبيعاتك) لا تسمح بنفادها أبداً. أصناف C قلل كمياتها.
- **تُشترى معاً:** ضع الصنفين متجاورين أو اعمل عليهما عرضاً مشتركاً.
- **تحديث الأسعار الجماعي:** بعد ارتفاع أسعار الموردين: اختر «هامش ربح مستهدف» مثلاً 20% ← «فقط الأصناف التي هامشها أقل» ← تقريب لأقرب 0.50 ← **👁 معاينة** ← **✓ تطبيق**. ثم اطبع ملصقات الأسعار الجديدة.

### 4.16 أسعار الجملة
1. في بطاقة المنتج: «سعر الجملة (اختياري)».
2. في بطاقة العميل: «مستوى السعر: جملة».
3. في نقطة البيع: عند اختيار هذا العميل (F4) تتحول أسعار الحبة لسعر الجملة تلقائياً، وتعود عند إلغائه.

### 4.17 شاشة الزبون
- وصّل شاشة ثانية (أو شاشة صغيرة موجهة للزبون) ← الإعدادات ← الطباعة ودرج النقود ← «شاشة الزبون».
- تعرض الأصناف والإجمالي والتوفير من العروض، ثم «شكراً — الباقي» بعد الدفع.

### 4.18 انقطاع الشبكة (للمحلات بعدة كاشيرات)
- إذا توقف الجهاز الرئيسي أو انقطع كابل الشبكة: يظهر شريط أصفر «⚠ وضع عدم الاتصال» والكاشير **يكمل البيع** نقداً أو بطاقة.
- **لا يمكن أثناء الانقطاع:** البيع الآجل، اختيار عميل، نقاط الولاء، المرتجعات.
- عند عودة الجهاز الرئيسي تُرحَّل الفواتير **وحدها** خلال 15 ثانية بأوقاتها الأصلية، ولا تتكرر أبداً.
- إن ظهرت «فاتورة متعذرة» (مثلاً انتهاء الترخيص) يراجعها المدير؛ تُعاد محاولتها تلقائياً.

### 4.19 ضريبة المدخلات (للمحلات المسجلة في الضريبة)
- في فاتورة المشتريات: «منها ضريبة القيمة المضافة (مدخلات)» ← اكتب الضريبة من فاتورة المورد أو اضغط «احسب بنسبة الضريبة».
- التقارير ← **ضريبة القيمة المضافة**: ضريبة المبيعات − ضريبة المشتريات = الصافي المستحق للدفع. أعطه لمحاسبك أو لمكتب الضريبة.

### 4.20 اللغة الإنجليزية
- من شاشة تسجيل الدخول (القائمة أسفل العنوان) أو الإعدادات ← بيانات المحل ← «اللغة / Language»، ثم أعد تشغيل البرنامج.
- الواجهة والفواتير والتقارير ورسائل واتساب تصبح بالإنجليزية، والشاشة من اليسار لليمين. بيانات المحل (أسماء الأصناف والعملاء) تبقى كما أدخلتها.

## 6. خطة تدريب الزبائن (للمطوّر)

### 6.1 قبل الزيارة
- [ ] اطلب من الزبون ملف أصنافه (Excel أو صور فواتير الموردين) وأرقام ديون الزبائن والموردين.
- [ ] جهّز ملف الاستيراد CSV مسبقاً (وفّر ساعات في المحل).
- [ ] أصدر مفتاح التفعيل بعد أخذ رمز الجهاز (أو اتركه على التجربة).
- [ ] اطبع «بطاقة الكاشير» (04_بطاقة_الكاشير.md) لكل كاشير ورقة.

### 6.2 الجلسة 1 — التركيب والإعداد (ساعة ونصف، مع المالك)
| الدقائق | المحتوى |
|---|---|
| 0-15 | التركيب، الطابعة، درج النقود، معالج الإعداد، كلمة مرور المدير |
| 15-45 | استيراد الأصناف، الأصناف بلا باركود كأزرار سريعة، الكراتين، رموز الميزان |
| 45-60 | إدخال ديون الزبائن والموردين القديمة، المستخدمون |
| 60-80 | النسخ الاحتياطي إلى Google Drive، لوحة المالك على جواله، رقم واتساب المالك |
| 80-90 | بيع تجريبي كامل ثم **حذف البيانات التجريبية** (أو ابدأ على قاعدة نظيفة) |

### 6.3 الجلسة 2 — الكاشير (45 دقيقة لكل كاشير أو مجموعة)
1. الدخول وفتح الوردية (5 د).
2. البيع: مسح، `3*`، موزون، +/−، حذف (10 د).
3. الدفع: نقدي، بطاقة، مختلط، آجل، الباقي (10 د).
4. العميل، النقاط، التعليق F6/F7، فحص السعر (10 د).
5. المرتجع وإغلاق الوردية وعدّ النقود (10 د).
- **اختبار الكاشير:** 10 عمليات بيع متنوعة في 5 دقائق بدون خطأ + إغلاق وردية مطابق.

### 6.4 الجلسة 3 — المدير (ساعة، بعد أسبوع من الاستخدام)
المشتريات والمرتجع للمورد، الطلبيات الذكية، الجرد، الصلاحية، العروض والولاء، الشيكات، التقارير الأسبوعية، المحاسبة والميزانية.
> بعد أسبوع يكون عنده بيانات حقيقية؛ التقارير تصبح مقنعة ومثيرة لاهتمامه.

### 6.5 المتابعة
- **اليوم 1:** اتصال مساءً: «كيف كان أول يوم؟».
- **اليوم 3:** راجع عن بُعد (AnyDesk) سجل العمليات والورديات: هل هناك عجز متكرر؟ خصومات كثيرة؟
- **اليوم 7:** الجلسة 3.
- **اليوم 30:** اجلس مع المالك على تقرير الأرباح والأصناف الراكدة. هذه اللحظة التي يقتنع فيها أن البرنامج «يدفع ثمنه» — **اطلب منه توصية/شهادة وفيديو قصير.**

### 6.6 نصائح للمدرب
- درّب على **بيانات المحل نفسه**، لا على أمثلة عامة.
- دع الكاشير يضغط بيده؛ لا تضغط عنه.
- علّم **الاختصارات** من اليوم الأول (F2، F12، Enter، +/−).
- ركّز مع المالك على **3 أرقام**: صافي الربح، الديون، النواقص. البقية تأتي مع الوقت.
- لا تشرح المحاسبة بمصطلحاتها؛ قل «ما تملك، ما عليك، ما يبقى لك».

## 7. أسئلة شائعة وحل المشاكل

| تعطل الجهاز | ركّب البرنامج على جهاز جديد واستعد آخر نسخة من مجلد Google Drive، ثم فعّل برمز الجهاز الجديد |
