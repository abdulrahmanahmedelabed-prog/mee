# دليل التدريب الشامل

> **لمن هذا الدليل؟** لصاحب المحل والمدير والكاشير. كل جزء مكتوب خطوة بخطوة.
>
> **تدرّب بدون خوف:** افتح **«نسخة التدريب»** من قائمة ابدأ في ويندوز. فيها سوبرماركت تجريبي كامل **بتاريخ عمل 3 سنوات** (مبيعات يومية بمواسمها، ورديات، مشتريات، ديون، شيكات، دفع إلكتروني)، في مكان منفصل **لا يمس بيانات محلك أبداً**. أول فتح يستغرق دقيقة أو دقيقتين لتجهيزها.
> الدخول في نسخة التدريب: `admin` / `admin` (مدير) أو `cashier` / `1234` (كاشير).

## 1. المفاهيم الأساسية في 5 دقائق

| المفهوم | المعنى |
|---|---|
| **الأدوار** | **مدير النظام** (كل شيء)، **مدير المحل** (كل شيء عدا الإعدادات والمستخدمين)، **كاشير** (بيع، فواتير، عملاء، صندوق) |
| **إذن المدير** | إذا احتاج الكاشير عملية ممنوعة (خصم كبير، تغيير سعر، تجاوز حد دين) تظهر نافذة يكتب فيها المدير اسمه وكلمة مروره فوراً، وتُسجَّل في سجل العمليات |
| **الوردية** | فترة عمل كاشير على جهاز: تبدأ بالمبلغ الموجود في الدرج وتنتهي بعدّ النقود. تكشف العجز والزيادة |
| **الوحدة** | لكل صنف وحدة أساسية (حبة) ويمكن إضافة وحدات أكبر (كرتونة = 24 حبة) بباركود وسعر خاص |
| **الدفعة** | كمية من صنف بتاريخ صلاحية واحد. البرنامج يبيع الأقرب انتهاءً أولاً |
| **الآجل** | بيع بالدين لعميل مسجّل (الدفتر) |
| **الجهاز الرئيسي والفرعي** | في المحلات ذات أكثر من كاشير: جهاز رئيسي يحفظ البيانات، والبقية تتصل به عبر شبكة المحل |

**قاعدة مهمة:** كل شيء يُحفظ فوراً، ولا يوجد زر «حفظ» عام. ونسخة احتياطية تُؤخذ تلقائياً كل يوم وعند إغلاق البرنامج.

## 2. التركيب وأول تشغيل

### 2.1 التركيب
1. شغّل ملف التثبيت **ShopAccounting-Setup** ← التالي ← تثبيت.
2. يظهر اختصار البرنامج على سطح المكتب، واختصار **«نسخة التدريب»** في قائمة ابدأ.
3. أول تشغيل قد يسأل جدار حماية ويندوز: اختر **سماح** (ضروري لأجهزة الكاشير الأخرى وللجوال).

### 2.2 أول دخول
1. المستخدم `admin` وكلمة المرور `admin`.
2. يطلب البرنامج **تغيير كلمة المرور فوراً**. اختر كلمة تتذكرها واحفظها عند المالك.
3. يظهر **معالج الإعداد الأول**:
   - اسم المحل والهاتف والعنوان والعملة والدولة والضريبة.
   - **نوع المحل:** «دكان أو محل صغير» يفتح البرنامج بالوضع المبسّط (بيع، مخزون، ديون، تقارير)، و«سوبرماركت أو محل كبير» يفتح كل الشاشات. يمكن تغييره لاحقاً.
   - **الجهاز بشاشة لمس:** إن كان جهاز الكاشير بشاشة لمس.
4. اضغط **ابدأ ✓**.

### 2.3 تجهيز البيانات (أهم ساعة مع البرنامج)
بالترتيب:
1. **المستخدمون:** الإعدادات ← المستخدمون ← «+ مستخدم» لكل كاشير (دور: كاشير).
2. **الطابعة:** الإعدادات ← الطباعة ودرج النقود ← اختر الطابعة وعرض الورق (80 أو 58 مم) ← «معاينة فاتورة تجريبية».
3. **شعار المحل (اختياري):** الإعدادات ← بيانات المحل ← **🖼 اختيار شعار...** أي صورة تعمل؛ البرنامج يجهّزها للطابعة.
4. **المنتجات** — ثلاث طرق:
   - **الأسرع:** المخزون ← **📤 تصدير إلى Excel** لتحصل على ملف بالأعمدة الصحيحة، املأه بأصنافك، احفظه بصيغة **CSV UTF-8**، ثم **📥 استيراد من Excel**.
   - **بالمسح:** في نقطة البيع امسح أي باركود غير مسجل ← يسألك البرنامج «إضافته كمنتج جديد؟».
   - **يدوياً:** المخزون ← **+ منتج جديد**.
5. **الأصناف بلا باركود** (خبز، خضار): في بطاقة المنتج اضغط **توليد** لباركود داخلي، وفعّل «مفضّل» ليظهر زراً سريعاً في نقطة البيع.
6. **الموزونات:** للملحمة والخضار ضع **رمز الميزان (PLU)** في بطاقة المنتج بنفس الرقم المبرمج في الميزان.
7. **الكراتين:** في بطاقة المنتج ← «+ إضافة وحدة»: كرتونة، عدد الحبات 24، باركود الكرتونة، سعرها.
8. **دفتر الديون القديم:**
   - العملاء ← **📥 استيراد الدفتر من Excel** ← «حفظ نموذج فارغ».
   - املأ النموذج (الاسم، الهاتف، العنوان، الدين الحالي، حد الدين) واحفظه **CSV UTF-8** ثم استورده.
   - الأسماء المكررة تُتخطى، وأي خطأ يظهر برقم السطر.
   - ونفس الشيء للموردين من شاشة الموردين.
9. **رأس المال والبنك (اختياري):** المحاسبة ← «عملية مالية» ← «رصيد بنك افتتاحي» أو «إيداع رأس مال».

## 3. تفعيل البرنامج

البرنامج يعمل **30 يوماً تجربة مجانية بكل المزايا**. بعدها يحتاج «مفتاح تفعيل» خاصاً بجهازك، يرسله لك مزوّد البرنامج.

**خطوات التفعيل (من حساب المدير):**
1. اضغط الزر البرتقالي **🔑 تفعيل البرنامج** أعلى الشاشة، أو: الإعدادات ← **الترخيص والتفعيل**.
2. يظهر **رمز هذا الجهاز** (مثل `4F1A-9C03-7B2E-D5A8`). اضغط **📱 طلب التفعيل عبر واتساب**؛ الرسالة جاهزة برمز الجهاز واسم المحل. (أو **📋 نسخ** وأرسله بأي طريقة.)
3. يرسل لك المزوّد **مفتاح التفعيل**: نص طويل يبدأ بـ `SA1.`
4. انسخ المفتاح كاملاً، والصقه في المربع، واضغط **✓ تفعيل**.
5. تظهر رسالة «تم التفعيل بنجاح ✓» ويختفي الشريط البرتقالي.

**مهم:**
- المفتاح يعمل على **هذا الجهاز فقط**. إذا غيّرت الجهاز أرسل رمز الجهاز الجديد للمزوّد.
- في المحل بعدة كاشيرات: التفعيل على **الجهاز الرئيسي فقط**، والأجهزة الأخرى تتبعه.
- إذا انتهت التجربة أو الاشتراك **يتوقف البيع فقط**. بياناتك وتقاريرك وديونك تبقى متاحة دائماً.

## 4. يوم عمل الكاشير

### 4.1 بداية الوردية
1. سجّل الدخول باسمك (ليس باسم المدير).
2. أول عملية بيع تطلب **فتح وردية**: عُدّ النقود في الدرج (الفكّة) واكتب المبلغ ← **🔓 فتح وردية**.

### 4.2 البيع — الطريقة السريعة
| ما تريد | ماذا تفعل |
|---|---|
| إضافة صنف | امسح الباركود (أو اكتب جزءاً من الاسم ثم Enter) |
| 3 قطع مرة واحدة | اكتب `3*` ثم امسح الباركود |
| صنف موزون | امسح ملصق الميزان — الوزن يُقرأ تلقائياً |
| زيادة/نقص الكمية | **+** أو **−** |
| حذف سطر | **Delete** |
| تغيير الكمية بالكتابة | **F8** |
| كرتونة بدل حبة | امسح باركود الكرتونة، أو **F5** على السطر |
| سعر مختلف | **F10** (يحتاج إذن مدير للكاشير) |
| خصم على الفاتورة | **F9** (مبلغ أو نسبة؛ فوق الحد يحتاج إذن مدير) |
| الزبون يسأل «بكم هذا؟» | زر **🔍 فحص سعر** — لا يُضاف للفاتورة |
| نقدي بالضبط بدون نافذة | **F12** |
| الدفع | **F2** أو **Enter** وخانة البحث فارغة |

**العروض تُطبّق وحدها:** إذا كان على الصنف عرض (مثل «اشترِ 2 واحصل على 1») يظهر سطر 🎁 تحت الإجمالي بقيمة الخصم. لا تفعل شيئاً.

### 4.3 نافذة الدفع
1. **نقدي:** اكتب المبلغ الذي أعطاك إياه الزبون، أو اضغط زر الورقة (10، 20، 50...). يظهر **الباقي للزبون** بخط كبير.
2. **بطاقة:**
   - إذا كان جهاز البطاقة مربوطاً بالبرنامج: اضغط **💳 دفع بالبطاقة عبر الجهاز**. يذهب المبلغ للجهاز، والزبون يمرر بطاقته. عند الموافقة يُسجَّل الدفع ويُطبع رقم الموافقة على الإيصال. عند الرفض تظهر رسالة البنك وتختار طريقة أخرى.
   - بدون ربط: اكتب المبلغ في الجهاز البنكي، ثم في خانة «بطاقة / تحويل» (أو «بطاقة بالكامل»).
3. **محفظة إلكترونية أو تطبيق بنكي:** اضغط زر الطريقة (مثل **📲 PalPay**). تظهر لك وللزبون (على شاشة الزبون) رقم حسابك ورمز QR والمبلغ. الزبون يدفع من تطبيقه ويريك الإشعار: تأكد من المبلغ واسم المحل، اكتب **رقم العملية**، ثم **✓ تم استلام المبلغ**. إن دفع جزءاً نقداً اكتبه في خانة النقد أولاً، والباقي يذهب للمحفظة.
4. **مختلط:** جزء نقدي وجزء بطاقة أو محفظة معاً.
5. **عملة أخرى** (إن فعّلها المدير): زر 💱 للعملة ← اكتب ما دفعه الزبون بها، ويحسب البرنامج الباقي بعملة المحل.
6. **آجل (دين):** اختر العميل أولاً (**F4**)، ثم «الباقي دين على العميل» أو «آجل بالكامل».
7. **Enter** لإتمام البيع. تُطبع الفاتورة إن كان خيار الطباعة مفعّلاً، ويُفتح درج النقود.

> في شاشات اللمس تظهر لوحة أرقام كبيرة داخل نافذة الدفع.

### 4.4 الزبون الدائم ونقاط الولاء
1. **F4** ← ابحث عن العميل بالاسم أو الهاتف (أو «+ عميل جديد»).
2. يظهر على الزر رصيد دينه ونقاطه 🎁.
3. لاستبدال النقاط: زر **🎁 استبدال نقاط** ← اكتب عدد النقاط ← يُخصم من الفاتورة.
4. بعد البيع يظهر «🎁 +25 نقطة» وتُطبع النقاط على الفاتورة.
5. عميل «جملة»: عند اختياره تتحول الأسعار لسعر الجملة تلقائياً.

### 4.5 مواقف يومية
| الموقف | الحل |
|---|---|
| الزبون نسي غرضاً وسيعود | **F6 تعليق** الفاتورة، اخدم الزبون التالي، ثم **F7** لاسترجاعها |
| طباعة الفاتورة الأخيرة مرة أخرى | **F11** |
| فتح الدرج لإعطاء فكّة | زر **💰 فتح الدرج** (يُسجّل في سجل العمليات) |
| صنف منتهي الصلاحية ظهر تحذير أحمر ⛔ | لا تبعه؛ أبلغ المدير ليتلفه من شاشة الصلاحية |
| الزبون يريد إرجاع صنف | الفواتير والمرتجعات ← ابحث برقم الفاتورة ← **↩ مرتجع** ← اختر الكمية ← نقداً أو خصم من الدين |
| زبون يسدد ديناً | العملاء ← اختره ← **💰 تسديد دفعة** |
| زبون يعطي شيكاً عن دينه | العملاء ← اختره ← **📥 استلام شيك** (يحتاج صلاحية المدير) |
| طلب أونلاين جاهز للاستلام | 🛵 الطلبات الأونلاين ← **🧾 تحويل لفاتورة** ← ادفع كالمعتاد |

### 4.6 إذا انقطعت الشبكة (المحلات بعدة كاشيرات)
- يظهر شريط أصفر «⚠ وضع عدم الاتصال»، و**تكمل البيع** نقداً أو بطاقة أو بالمحفظة.
- **لا يمكن أثناء الانقطاع:** البيع الآجل، اختيار عميل، نقاط الولاء، المرتجعات.
- عند عودة الاتصال تنتقل الفواتير **وحدها** إلى الجهاز الرئيسي بأوقاتها الأصلية، ولا تتكرر.

### 4.7 نهاية الوردية
1. الصندوق والورديات ← **🔒 إغلاق الوردية وعدّ النقود**.
2. عُدّ النقود بالفئات (200، 100، 50...) — البرنامج يجمعها. العملة الأجنبية تُعدّ بما يعادلها بعملة المحل.
3. يظهر **المتوقع** و**المعدود** و**الفرق** (عجز أو زيادة).
4. **🖨 طباعة تقرير الوردية** وسلّمه مع النقود للمدير.

> **قاعدة ذهبية للكاشير:** لا تأخذ ولا تضع مالاً في الدرج بدون تسجيله: استخدم **⬆ سحب نقدي** أو **⬇ إدخال نقدي** مع السبب. وإلا سيظهر عجز أو زيادة باسمك.

## 5. مهام المدير وصاحب المحل

### 5.1 كل صباح (5 دقائق)
1. **🤖 المستشار الذكي:** التوصيات مرتبة من الأخطر (⛔ أحمر) إلى الإيجابي (✅ أخضر). كل توصية فيها رابط ينقلك للإجراء: صنف رابح سينفد، بضاعة قاربت على الانتهاء، زبون توقف عن الشراء، عجز متكرر...
2. **لوحة التحكم:** مبيعات أمس، النواقص، الصلاحية، **الشيكات المستحقة خلال أسبوع**.
3. **الصلاحية:** أتلف المنتهي، واعمل عرضاً على القريب من الانتهاء.

### 5.2 استلام بضاعة من المورد
1. الموردون والمشتريات ← **🧾 فاتورة مشتريات جديدة** ← اختر المورد.
2. امسح باركود كل صنف (أو باركود الكرتونة للشراء بالكرتونة).
3. عدّل الكمية وتكلفة الوحدة وسعر البيع، واكتب **الصلاحية** (مثل 2027-03-31) للأصناف الغذائية.
4. إن كنت مسجلاً في الضريبة: «منها ضريبة القيمة المضافة» ← اكتبها من فاتورة المورد أو «احسب بنسبة الضريبة».
5. «دفع كامل المبلغ» أو اكتب المدفوع الآن؛ الباقي يصبح ديناً للمورد.
6. **حفظ الفاتورة**: يزيد المخزون وتُحدَّث التكلفة تلقائياً.

### 5.3 إرجاع بضاعة للمورد
الموردون ← اختر المورد ← **↩ مرتجع للمورد** ← امسح الأصناف ← الكمية والسعر المتفق عليه ← السبب ← حفظ. يُخصم من المخزون ومن حساب المورد.

### 5.4 الطلبيات الذكية (بدل الوقوف أمام الرفوف بورقة وقلم)
1. 🧠 الطلبيات الذكية ← «احسب سرعة البيع من آخر 30 يوماً، واطلب ما يكفي 14 يوماً» ← **🔄 احسب**.
2. اختر المورد من القائمة.
3. **📱 إرسال الطلبية للمورد (واتساب)** — الرسالة جاهزة بالأصناف والكميات بالكرتونة.
4. عند وصول البضاعة: **🧾 تحويلها لفاتورة مشتريات** — الأصناف والكميات جاهزة، عدّل الأسعار واحفظ.

### 5.5 المخزون والجرد
- **📋 جرد:** اكتب الكمية الفعلية على الرف؛ الفرق يُسجَّل تلقائياً (نقص = خسارة). ويمكن الجرد من الجوال (الجزء 6).
- **± تعديل الكمية:** لتالف أو هدية أو استهلاك (اكتب السبب: «تالف» أو «منتهي» يُحتسب خسارة).
- **📜 حركة الصنف:** كل ما دخل وخرج من الصنف ومن قام به.
- **🏷 طباعة ملصقات:** ملصقات أسعار بالباركود.
- **النواقص فقط:** قائمة ما وصل للحد الأدنى.

### 5.6 الأسعار
- **سعر الجملة:** في بطاقة المنتج «سعر الجملة»، وفي بطاقة العميل «مستوى السعر: جملة».
- **تحديث الأسعار الجماعي** (بعد ارتفاع أسعار الموردين): المستشار الذكي ← تحديث الأسعار الجماعي ← «هامش ربح مستهدف» مثلاً 20% ← «فقط الأصناف التي هامشها أقل» ← تقريب لأقرب 0.50 ← **👁 معاينة** ← **✓ تطبيق**. ثم اطبع ملصقات الأسعار الجديدة.
- **تحليل ABC:** أصناف A (تصنع 80% من مبيعاتك) لا تسمح بنفادها أبداً. أصناف C قلل كمياتها.
- **تُشترى معاً:** ضع الصنفين متجاورين أو اعمل عليهما عرضاً مشتركاً.

### 5.7 الديون
- **العملاء والديون:** كشف حساب لكل عميل، **🖨 طباعة الكشف**، **💬 تذكير واتساب**، و**📣 تذكير جماعي للمدينين** (رسالة لكل مدين بضغطة).
- **حد الدين:** في بطاقة العميل. البرنامج يمنع تجاوزه إلا بإذن المدير.
- **⚖ تسوية:** مسامحة بمبلغ بسيط أو تصحيح (تظهر في التقارير كتسوية).

### 5.8 الشيكات
- **استلام شيك من عميل:** 🏦 الشيكات ← 📥 ← العميل، المبلغ، الرقم، البنك، تاريخ الاستحقاق.
- **إعطاء شيك لمورد:** 📤 ← المورد... (أو من شاشة الموردين ← «📤 شيك مؤجل»).
- **يوم الاستحقاق:** اختر الشيك ← **✓ صُرف في البنك**، أو **↩ راجع** (يعود الدين تلقائياً).
- الألوان: 🟥 فات موعده ولم يُحدَّث، 🟧 خلال أسبوع.

### 5.9 العروض ونقاط الولاء
- 🎁 العروض والولاء ← **+ عرض جديد**:
  - **اشترِ واحصل مجاناً:** الصنف، اشترِ 2، واحصل على 1.
  - **كمية بسعر ثابت:** 3 قطع بـ 10.
  - **خصم نسبة:** على صنف أو **فئة كاملة** (مثل المنظفات 15%).
  - تاريخ البداية والنهاية؛ العرض يتوقف وحده.
- **نقاط الولاء:** الإعدادات ← نقاط الولاء ولوحة المالك. المثال الموصى به: نقطة لكل 1 شيكل، النقطة = 0.05، أقل استبدال 100 ← الزبون يسترد 5%.

### 5.10 الدفع الإلكتروني (المحافظ وتطبيقات البنوك)
**الإعداد (مرة واحدة):** الإعدادات ← **الدفع الإلكتروني** ← **✨ اقتراحات لبلدي** (أو «+ إضافة طريقة دفع»):
- **الاسم** كما يعرفه الزبون، و**رقم الحساب أو الهاتف أو الاسم المستعار** الذي يحوّل إليه.
- **يصل المال إلى:** «رصيد المحفظة» لمحافظ الجوال، أو «حساب البنك مباشرة» للتحويل البنكي الفوري.
- **نص رمز QR (اختياري):** إن كان للمحل رمز QR رسمي في تطبيق المحفظة، ضع نصه هنا ليظهر للزبون. بدونه يظهر رمز برقم الحساب.
- يُفضَّل تفعيل «إلزام الكاشير بكتابة رقم العملية».

**المطابقة (أسبوعياً):** التقارير ← **الدفع الإلكتروني**: مجموع كل طريقة (مبيعات + تسديد ديون). اختر طريقة لترى عملياتها برقم كل عملية، وطابقها مع كشف المحفظة أو البنك. أي عملية في البرنامج وليست في الكشف = إشعار مزيّف أو خطأ؛ راجعها فوراً.

**تحويل رصيد المحفظة للبنك:** المحاسبة ← **➕ عملية مالية** ← «تحويل رصيد المحافظ الإلكترونية إلى البنك» بالمبلغ الذي وصل البنك، ثم «عمولة خصمتها المحفظة الإلكترونية» بالفرق. رصيد «المحافظ الإلكترونية» في الميزانية يجب أن يساوي رصيدك في التطبيق.

> **مهم للكاشير:** لا تسلّم البضاعة قبل رؤية إشعار الدفع الصحيح في جوال الزبون. صور الإشعارات قد تُزوَّر؛ المطابقة الأسبوعية تكشف ذلك.

### 5.11 المصاريف
💸 المصاريف ← النوع (كهرباء، إيجار...) ← المبلغ ← «من الصندوق» إذا دُفع من الدرج، وأزِل العلامة إذا دفعه المالك من جيبه أو من البنك.

### 5.12 التقارير (ماذا تقرأ ومتى)
| التقرير | متى | ماذا تبحث |
|---|---|---|
| الأرباح والخسائر | أسبوعياً وشهرياً | صافي الربح، هامش الربح (الجيد للبقالة 15-25%) |
| **ملخص الفترات** (يومي/أسبوعي/شهري/سنوي) | نهاية كل أسبوع وشهر وسنة | قارن الفترات: أين ارتفع الربح أو انخفض، وكيف تتغير طرق الدفع. اختر «آخر 3 سنوات» و«سنوي» لترى نمو المحل |
| الدفع الإلكتروني | أسبوعياً | مطابقة كل محفظة وتطبيق بنكي مع كشفه |
| الأصناف الأكثر مبيعاً (حسب الربح) | شهرياً | ما الذي يربحك فعلاً؛ لا ينفد أبداً |
| أصناف راكدة | شهرياً | مال مجمّد: اعمل عليها عرضاً أو أرجعها للمورد |
| ساعات الذروة | عند تنظيم الدوام | متى تحتاج كاشيراً إضافياً |
| حسب الكاشير | أسبوعياً | الخصومات الكثيرة من كاشير معيّن |
| ضريبة القيمة المضافة | عند تقديم الإقرار | ضريبة المبيعات − ضريبة المشتريات = الصافي المستحق |
| سجل العمليات | عند الشك | من غيّر سعراً، من فتح الدرج، من حذف صنفاً |

### 5.13 المحاسبة والميزانية (لصاحب المحل والمحاسب)
- **الميزانية العمومية:** كم يملك المحل وكم عليه وصافي حق المالك.
- **قائمة الدخل:** الربح الحقيقي للفترة.
- **ميزان المراجعة:** أعطه للمحاسب القانوني (📤 تصدير أو 🖨 طباعة). انقر مرتين على أي حساب لكشفه.
- **دفتر اليومية وكشف الحساب:** المبيعات تظهر قيداً واحداً لكل يوم (أوضح). ضع علامة «تفصيل كل فاتورة» لرؤية كل فاتورة.
- **➕ عملية مالية:** رأس مال، إيداع في البنك، سحب من البنك، شراء معدات، قرض وسداد قسط.
- **القيود اليدوية** للمحاسب فقط، ويمكن إلغاء قيد (يبقى ظاهراً كملغى).
> اقرأ دليل «المحاسبة ببساطة» لفهم المصطلحات بلغة سهلة.

### 5.14 ملخص اليوم على واتساب
الإعدادات ← نقاط الولاء ولوحة المالك ← «رقم واتساب المالك». ثم من لوحة التحكم: **📱 ملخص اليوم للمالك** — رسالة بمبيعات اليوم وربحه ونقده وتنبيهاته.

### 5.15 عدة أجهزة كاشير
1. في الجهاز الرئيسي: الإعدادات ← هذا الجهاز والشبكة ← إعداد الشبكة ← «جهاز رئيسي». سجّل العنوان ورمز الربط.
2. في كل كاشير: «نقطة بيع فرعية» ← العنوان ورمز الربط ← 🔌 اختبار الاتصال.
3. أعد تشغيل البرنامج في كل الأجهزة. لكل جهاز ورديته وصندوقه وطابعته.
4. عدد الأجهزة المسموح حسب باقة التفعيل.

### 5.16 النسخ الاحتياطي (لا تتجاهله أبداً)
- نسخة تلقائية كل يوم وعند الإغلاق.
- الإعدادات ← النسخ الاحتياطي ← **نسخة ثانية تلقائية في مجلد سحابي**: اختر مجلداً داخل Google Drive أو OneDrive. هذا ما ينقذك إذا تعطل الجهاز أو سُرق.
- الاستعادة: «♻ استعادة المحددة» (من الجهاز الرئيسي فقط).

### 5.17 إعدادات تناسب محلك
| الإعداد | أين | ماذا يفعل |
|---|---|---|
| **الوضع المبسّط** | الإعدادات ← البيع والمخزون | يخفي المحاسبة والشيكات والعروض والطلبيات والمستشار. أزل العلامة متى احتجتها؛ لا تُحذف أي بيانات |
| **شاشة لمس** | الإعدادات ← البيع والمخزون | أزرار أكبر ولوحة أرقام (لهذا الجهاز فقط، بعد إعادة التشغيل) |
| **شاشة الزبون** | الإعدادات ← الطباعة ودرج النقود | شاشة ثانية تعرض للزبون الأصناف والإجمالي والتوفير والباقي |
| **جهاز الدفع بالبطاقة** | الإعدادات ← الطباعة ودرج النقود | «يدوي» بدون ربط (الافتراضي)، «محاكي» للتدريب، «جسر الجهاز البنكي» بعد أن يركّب لك المزوّد الربط مع بنكك. ثم «💳 فحص الاتصال» |

| **عملات إضافية** | الإعدادات ← العملة والضريبة | مثل `USD=3.65,JOD=5.15`؛ يظهر زر لكل عملة في نافذة الدفع |
| **اللغة / Language** | شاشة الدخول أو الإعدادات ← بيانات المحل | الواجهة والفواتير والتقارير بالإنجليزية (بعد إعادة التشغيل) |

## 6. الجوال: التطبيق ولوحة المالك والمتجر

### 6.1 تطبيق الجوال (أندرويد)
1. ثبّت التطبيق (من المزوّد أو من المتجر).
2. على جهاز الكاشير الرئيسي: الإعدادات ← نقاط الولاء ولوحة المالك ← فعّل «تشغيل لوحة المالك على الجوال» ← يظهر **رمز QR لربط تطبيق الجوال**.
3. في التطبيق: **📷 مسح رمز الربط** ← امسح الرمز من الشاشة. (الجوال يجب أن يكون على واي فاي المحل.)
4. سجّل الدخول باسم المستخدم وكلمة المرور نفسها التي في البرنامج.
5. زر 📷 يمسح باركود أي صنف: يظهر سعره وكميته وصلاحيته. ومن لديه صلاحية المخزون يكتب «الكمية الفعلية على الرف» ← **حفظ الجرد**.
6. من قائمة التطبيق (⋮): **لوحة المالك**، أو **المتجر**، أو تغيير المحل.

> **آيفون:** افتح العنوان الظاهر تحت «لوحة المالك» في الإعدادات من متصفح سفاري، ثم «إضافة إلى الشاشة الرئيسية».

### 6.2 لوحة المالك
مبيعات اليوم وربحه، النقد في الأدراج، الديون، التنبيهات، والمبيعات آخر 7 أيام — من جوالك داخل المحل.
**من خارج المحل:** اطلب من المزوّد تركيب اتصال آمن (مثل Tailscale المجاني) على جهاز المحل وجوالك.

### 6.3 المتجر الأونلاين والطلبات 🛵
1. الإعدادات ← **المتجر الإلكتروني** ← فعّل المتجر، التوصيل، رسومه، وأقل قيمة للطلب.
2. شاشة **🛵 الطلبات الأونلاين** تعرض رابط المتجر: انشره للزبائن (واتساب، رمز QR على باب المحل، فيسبوك).
3. عند وصول طلب يظهر رقم على زر القائمة مع صوت تنبيه:
   **👨‍🍳 قيد التجهيز** ← **✅ جاهز** ← **📱 إبلاغ الزبون** ← عند الاستلام **🧾 تحويل لفاتورة**.

## 8. أسئلة شائعة وحل المشاكل

| المشكلة | الحل |
|---|---|
| الباركود لا يُقرأ | تأكد أن مؤشر الكتابة في خانة البحث (Esc يعيده). جرّب الماسح في برنامج Notepad: إن لم يكتب فالمشكلة في الماسح |
| «الكمية غير كافية في المخزون» | الصنف لم يُدخل بفاتورة مشتريات أو الجرد غير صحيح. أدخل الكمية، أو (بحذر) فعّل «السماح بالبيع عند نفاد الكمية» |
| الطابعة لا تطبع | الإعدادات ← الطباعة ← اختر الطابعة الصحيحة وعرض الورق ← معاينة فاتورة تجريبية. تأكد أن الطابعة معرّفة في ويندوز |
| الدرج لا يُفتح | الإعدادات ← الطباعة ودرج النقود ← نوع الاتصال (عبر الطابعة غالباً) ← «💰 تجربة فتح الدرج» |
| الزبون يقول «حوّلت» ولا يظهر في تطبيق المحل | لا تسلّم البضاعة. اطلب منه فتح التطبيق أمامك ورؤية العملية باسم محلك ورقمها |
| جهاز البطاقة «تعذر الاتصال» | الإعدادات ← الطباعة ودرج النقود ← «💳 فحص الاتصال». إن استمر: ادفع بالطريقة اليدوية وتواصل مع المزوّد |
| عجز متكرر في الصندوق | سجل العمليات: فتح الدرج اليدوي، المرتجعات النقدية، الخصومات؛ تأكد أن السحوبات تُسجَّل بـ «سحب نقدي» |
| الجهاز الفرعي «تعذر الاتصال» | الجهاز الرئيسي يعمل؟ على نفس الشبكة؟ جدار الحماية سمح للبرنامج؟ عنوان الجهاز الرئيسي لم يتغير؟ |
| تطبيق الجوال «تعذر الوصول إلى جهاز المحل» | الجوال على واي فاي المحل؟ البرنامج يعمل على الجهاز الرئيسي؟ امسح رمز الربط من جديد |
| «وصلت للحد الأقصى من الأجهزة المرخّصة» | باقتك لعدد أقل من الأجهزة؛ اطلب من المزوّد ترقية الباقة |
| «انتهت الفترة التجريبية» | البيع متوقف والتقارير تعمل. فعّل البرنامج (الجزء 3) |
| «مفتاح التفعيل لجهاز آخر» | المفتاح صادر لجهاز غير هذا. أرسل للمزوّد رمز هذا الجهاز ليصدر مفتاحاً جديداً |
| «صيغة مفتاح التفعيل غير صحيحة» | انسخ المفتاح **كاملاً** من أوله `SA1.` حتى آخر حرف، بدون زيادة أو نقص |
| نسيت كلمة مرور المدير | شاشة الدخول ← **«نسيت كلمة المرور؟»** ← أرسل رمز الجهاز للمزوّد عبر واتساب ← اكتب الرمز الذي يصلك وكلمة مرور جديدة. لا تُحذف أي بيانات |
