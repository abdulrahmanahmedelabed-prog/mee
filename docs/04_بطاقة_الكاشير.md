# 🧾 بطاقة الكاشير — اطبعها وضعها بجانب الشاشة

## بداية الدوام
1. ادخل **باسمك**.  2. عُدّ الفكّة في الدرج.  3. **فتح وردية** بالمبلغ.

## أزرار البيع
| المفتاح | الوظيفة | المفتاح | الوظيفة |
|:---:|---|:---:|---|
| **امسح** | إضافة صنف | **F2** | الدفع |
| **3\*باركود** | 3 قطع | **F12** | نقدي بالضبط |

| **⬆ رقم صحيح** | فاتورة بلا كسور | | |

## الدفع
- اكتب ما أعطاك الزبون ← انظر **الباقي** ← **Enter**.
- **بطاقة**: زر **💳 دفع بالبطاقة عبر الجهاز** إن كان الجهاز مربوطاً، وإلا اكتب المبلغ في خانة البطاقة.
- **محفظة / تطبيق بنكي**: زر **📲** الطريقة ← الزبون يدفع ويريك الإشعار ← اكتب **رقم العملية** ← **✓ تم استلام المبلغ**. لا تسلّم قبل رؤية الإشعار.
- **دين**: اختر العميل (F4) ثم «آجل».
- 🎁 العروض تُحسب **وحدها**. نقاط الزبون: زر **🎁 استبدال نقاط**.

## ممنوع ✋
- ❌ لا تبع صنفاً ظهر عليه **⛔ منتهي الصلاحية**.
- ❌ لا تأخذ أو تضع مالاً في الدرج بدون **سحب نقدي / إدخال نقدي**.
- ❌ لا تعطِ كلمة مرورك لأحد، ولا تعمل على حساب غيرك.

## مرتجع
الفواتير والمرتجعات ← رقم الفاتورة ← **↩ مرتجع** ← الكمية ← نقداً أو من الدين. يُرد **بسعر الفاتورة نفسها** حتى لو تغيّر السعر.

## نهاية الدوام
**الصندوق ← 🔒 إغلاق الوردية** ← عُدّ بالفئات ← **🖨 طباعة التقرير** ← سلّم النقود والتقرير للمدير.
