# برنامج المحاسبة ونقاط البيع

> **English:** Point of sale + real accounting for shops and supermarkets, offline-first, Arabic & English. See the [English product sheet](docs/Product_Sheet_EN.md).

برنامج بيع ومحاسبة للدكاكين والسوبرماركت والمحلات الصغيرة: يعمل بدون إنترنت، يبيع بسرعة، يتذكر الديون والشيكات والصلاحية، ويقول لصاحب المحل كل يوم كم ربح فعلاً — على جهاز واحد أو عدة أجهزة كاشير، ومع تطبيق للجوال.

![نقطة البيع](docs/pos.png)

### ✨ أبرز ما يميّزه
- **واجهة عصرية بطابع تطبيقات الجوال:** بطاقات واضحة، أزرار كبيرة، وخط عربي حديث مضمَّن في البرنامج.
- **محاسبة بمعايير المحاسب القانوني:** كل نقد في الدرج يمر بوردية، والمرتجع يُعاد بنفس طريقة الدفع، وكل نقص أو زيادة في المخزون يظهر في الأرباح، ونقاط الولاء التزام في الميزانية، وضريبة المدخلات تُعكس مع مرتجع المشتريات.
- **مدقق مالي داخلي:** 30 إجراء تدقيق على كل العمليات، يكشف التلاعب ويصدر رأياً ودرجة وتقريراً للطباعة.
- **مُختبر تحت الضغط:** 20 كاشيراً معاً على 3 سنوات من بيانات سوبرماركت، وانقطاع الكهرباء أثناء البيع — بلا فاتورة ضائعة أو مكررة.

## ابدأ من هنا

| الخطوة | ماذا تفعل |
|---|---|
| **1. نزّل البرنامج** | من روابط التحميل أعلاه. أو ابنِه على جهازك: انقر مرتين على `build_exe.bat` |
| **2. جهّز التفعيل** | انقر مرتين على `license_manager.bat` ← «إنشاء مفاتيحي» (مرة واحدة). منه تصدر مفاتيح التفعيل لزبائنك — الشرح في [دليل التفعيل](docs/07_دليل_التفعيل.md) |
| **3. تدرّب** | بعد التثبيت افتح «نسخة التدريب» من قائمة ابدأ: سوبرماركت كامل بتاريخ 3 سنوات (الدخول `admin` / `admin`) |
| **4. بِع** | [دليل التسويق والبيع](docs/05_دليل_التسويق_والبيع.md) والفيديو الإعلاني الجاهز في `marketing/ad` |

## المزايا باختصار

| | |
|---|---|
| 🧾 **البيع** | باركود، ميزان، حبة وكرتونة، عروض تلقائية، نقاط ولاء، أسعار جملة، نقدي وبطاقة وآجل وعملات أخرى، جاهز للربط مع جهاز البطاقة البنكي |
| 📲 **الدفع الإلكتروني** | المحافظ وتطبيقات البنوك: رقم الحساب ورمز QR للزبون، رقم العملية، تقرير مطابقة، حساب مستقل في الميزانية |
| 📦 **المخزون** | الصلاحية (يبيع الأقرب انتهاءً أولاً)، جرد، طلبيات ذكية للموردين عبر واتساب، ملصقات أسعار |
| 👥 **الديون** | دفتر لكل زبون، حد دين، تذكير واتساب، شيكات مؤجلة، استيراد الدفتر القديم من Excel |
| 💰 **الأرباح** | الربح الحقيقي، ملخص يومي وأسبوعي وشهري وسنوي، ميزانية وميزان مراجعة للمحاسب، إقرار الضريبة |
| 🔎 **التدقيق المالي** | 30 إجراء تدقيق على كل العمليات، كشف التلاعب عند الكاشير، أعمار الديون، رأي ودرجة وتقرير للطباعة |
| 🤖 **المستشار الذكي** | تنبيه يومي بما يخسّر المحل وما يجب طلبه |
| 🔒 **الرقابة** | ورديات وكشف عجز الصندوق، إذن المدير، سجل العمليات، نسخ احتياطي تلقائي |
| 📱 **الجوال** | تطبيق أندرويد (أسعار، جرد بالكاميرا، لوحة المالك)، متجر أونلاين، ملخص اليوم بواتساب |
| 🖥 **يناسب كل محل** | واجهة عصرية سهلة، وضع مبسّط للدكان، عدة كاشيرات للسوبرماركت، شاشة لمس، عربي وإنجليزي، يعمل بدون إنترنت |

## للمطوّر

### التشغيل من الكود
```bash
pip install -r requirements.txt
python main.py            # البرنامج
python main.py --demo     # نسخة التدريب (3 سنوات من البيانات؛ SHOP_DEMO_DAYS=90 لمدة أقصر)
```

### الاختبارات
```bash
pip install pytest
python -m pytest tests
```

### هيكل المشروع
```
main.py              التشغيل
core/                المنطق (بيع، مخزون، ديون، محاسبة، ترخيص، شبكة...) بدون واجهة
ui/                  الشاشات (PySide6)، التصميم في ui/style.py والخط في ui/fonts (رخصة OFL)
docs/                الأدلة (تُعرض أيضاً داخل البرنامج)
i18n/                الترجمة الإنجليزية
android/             تطبيق أندرويد
installer/           ملف التثبيت (Inno Setup)
marketing/ad/        الفيديو الإعلاني وأداة إنتاجه
tools/               أدوات المطوّر (مدير التفعيل، البيانات التجريبية، جسر جهاز البطاقة)
tests/               الاختبارات
```
